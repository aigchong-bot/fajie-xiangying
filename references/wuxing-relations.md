# 生克 → 断语（v2）
相生顺序：木→火→土→金→水→木。相克：金克木，木克土，土克水，水克火，火克金。【原】

| 关系（以太极点“我”为准） | 六亲/社会角色 | 断语方向 | 依据 |
|---|---|---|---|
| 生我 | 母亲；也可以是领导 | 被滋养，有贵人帮；妻生夫就是旺夫，对丈夫照顾无微不至，丈夫爱回家 | |
| 我生 | 孩子 | 付出、泄气；花钱多、办事费劲；有压力（债务、经济紧） | |
| 我克 | 妻财、下属；能赚到其钱的人 | 财运好；能管住人、能当领导 | |
| 克我 | 官鬼、领导 | 想法被压下去；夫妻中一方说话伤人 | |
| 比和 | 兄弟、朋友 | 互相帮扶、有原则，但两人都犟 | |
| 男生女 | — | 男方对女方百依百顺 | |
| 男克女 | — | 可能家暴、脾气大 | |
| 女克男 | — | 男的容易当官或当老板 | |

⚠ 矛盾③： 说“大姓名学没有相克，只有相生与间接相生”（克被看作“逆缘成就”），但 A 里大量用克来断财和官。处理办法：照 A 的做法使用克，但措辞上按 B 的意思处理，克也可以理解为“成就”，避免只说负面。

## 字形读法【原】
| 读法 | 规则 | 依据 |
|---|---|---|
| 方位 | 字的上方对南，下方对北，左对东，右对西；例如氵在左，就断家的东边有水 | |
| 距离 | 部件离得远：夫妻感情疏远、分居、常出差；先写的部件“先跑了” | |
| 环抱 | 下部（属阴）的部件呈环抱状：孩子归女方，和母亲更亲 | |
| 笔画数量和长短 | 两横可断两个孩子；短的为阴为女，长的为阳为男，先写的先生；长的更受偏爱 | |
| 口的位置 | 在内或右下：对熟人和家里人话多；在外：对谁都说；在中间：对上对下都说；口一小一大：后写的大口说得多 | |
| 书写状态 | 写得潦草要解读；写三点水时笔没水了，断“缺水” | |
| 竖穿口（中） | 刚要说话就被打断；女的爱反驳 | |
| 三层结构 | 只在问感情时断有一方有外遇 | |

  - 太极点属火的学历高；属金的学历一般；属土的学历差一些；**属水的学历高**（v3.3 按 300dpi 重看 p32 更正，旧版误作“属木”）。属木：课件未单列，不下学历高低结论。

- 身材（p31）：太极点为阳则胖，为阴则瘦。
- 字形笔画技巧（p23–24，共 21 条，节选）：

# v3.1 补充
## 配偶认定的优先顺序（课件 p42，原始）
“断婚姻主要是从字的结构、五行、太极点来看：上下结构上为男下为女，左右结构左为男右为女，内外结构外为男内为女……**以男女太极点的五行关系断婚姻**。”
例子：
- 坚：男取刂，属木；女取土。二者相克，婚姻不顺。
- 娜：女旁代表丈夫，阝代表本人，两个都是土，比和，主争吵。
- 某“丽”字名：丽字上面一横为土，代表老公；下面两个“月”属水，为财、为女人。断有外遇、二婚。

**规则**：问婚姻或配偶时，**先用方位读法**：太极点所在的字里，与本人位置相反的那一部分就是配偶。六亲规则（男命妻＝我克，女命夫＝官鬼）只用于两种情况：一是没有方位可分的独体字，二是查看配偶以外的六亲。p42 某“丽”字名的例子里两种读法一起用，所以允许两种都写，但方位读法排在前面。【原 p42；推：独体字退回六亲】

## 女命火形（课件 p24 第 15 条，原始）
女人姓名中太极点属火的，多数主此人长得漂亮美丽，干净利索。

## 独体字的配偶（v3.1，强调）
独体字没有方位，配偶一律用六亲规则：男命以我克者为妻，女命以克我者为夫。字里没有对应五行时，写“配偶星不显”。**不能套用“男生女、百依百顺”之类的方位断语**【推，依据 p42 规则只适用于有结构的字】。

## “人际”的定义
“人际”只指六亲角色（p15）：兄弟对应朋友、同事、竞争者；官鬼对应领导、上司；子孙对应晚辈、下属、学生；父母对应长辈、贵人。另有 的上下级读法。除此之外的人际断语没有依据，不要输出。

## 生克的具体含义（p10）
- 主生方（我生）：泄气、花销大、付出多；测婚姻为“我投入多”；测求财为投入不少、利润少；测合伙为对方依赖我、反添麻烦。
- 受生方（生我）：得益、得贵人；测婚姻为对方疼爱自己、本人有福气；测求财为财顺、顾客多；测合伙为别人主动出力。
- 受克方（克我）：受损、不顺；测婚姻为俩人无缘、争吵、易离；求财难。例外：问当官时克我为官鬼，反主升迁。
- 主克方（我克）：霸道、独断；测婚姻为强势对待对方；求财有财但费力、辛苦；与下属关系不好。
- 原则：生有泄有益，克有耗有伤，两面都要说（p10 末段）。

## 双重性格（p27）
- 字的上部笔画代表外在性格，下部笔画代表内在性格。
- 太极点五行被字内笔画生 → 该五行性格更旺（例：金被土生，义气且忠厚）；被克或被泄 → 该五行性格反面化（例：金被火克或被水泄，变成不讲信用、意志脆弱）。

## 长相补充（p30）
- 长相看太极点五行，按五行原则断，再看受生/受克/受泄的影响：金被泄后不能很白；水受金生则白；木本色青，受生更青，受克则偏白。
- 额头：太极点五行生乾兑金→额头小；克乾兑金→额头大；与之比和→额头大；被乾兑金生→额头大；被克→额头小。太极点与鼻子五行比和→鼻子大。
- 例：“伟”亻为火，性急，无生扶更急躁，但文章、字写得好；“宏”主要按金断，参考宀；“珍、王”为金男，被火克则性格有变；问女也看金多泄，文明、长得漂亮。
- 面部八宫×年龄段（p30 下半）：属大运流年，**不执行**，见 menu 维护说明。

## 学业补充（p32）
- 偏科：水偏理科；木主条理，也有理科含义；火偏文科；金代表口才，外语一般好。【原】
- 29 岁前看原始学历；比劫（比和）多，易因交友不慎影响学业。
- 流年考学（生我利、比和难、我克辛苦可能考上、克我难、我生付出大结果不理想）：需要流年，**本 Skill 不执行**，只在用户给出具体年份时提示“暂不支持”。

## 六亲补充（p46）
- 六亲个数按河图数：水1/6、火2/7、木3/8、金4/9、土5/10（10 也可作 1，代表独生）。例：某“静”字名，太极点“月”水；生我者金→母亲姐妹 4 个；我克者火→父亲兄弟 2 或 7 个。【原】输出时只说“可能”，并注明这是一种推算参考【推：措辞】。
