# 偏旁/笔画 → 五行 对照表（v3）

来源：课件 PDF《姓名学神断精华版》第 17–20 页「汉字的基本笔画名称五行属性表」。全部属于【原始】。
格式：部件=五行（课件原注）。页码写在每组标题后。原图是扫描件，个别字形识别没把握的标了 [存疑]。

## 总规则
- 基本笔画（p17、p23）：横＝土，竖＝木，撇＝火，点＝水，捺＝金；乙＝木。
- 判定思路（p17–20 注释）：
  - 取部件本义，如 水、火、土。
  - 取八卦类象：兑＝口/金，乾＝金，坤＝土/布/母/女，艮＝山/土，离＝火/马/鸟，坎＝水/耳，震、巽＝木。
  - 取地支、天干、生肖：子、鼠＝水，丑、牛＝土，寅、卯＝木，巳＝火，申＝金。
  - 取颜色：白＝金，青＝木，赤＝火，黑＝水。
  - 取河图洛书数：49＝金。
  - 部件内部有生克时，按受克方或受生方定五行，如 十、厂、卜、亻、才、手。
  - 带勾的部件归金，如 ⺈、力、刂、见、殳。
- 五行难确定时，**以第一笔定五行**（p19 “爪爫”条）。
- 课件提醒：“特殊笔画要死记”（冖、兀）。

## 五行形象（性格、长相、身材、肤色）
- 性格（p27）：
  - 土：忠厚守信，认死理，“八个老牛拉不回”。
  - 金：讲义气，爱打抱不平，性急。
  - 水：聪明，有谋略，变通，多情。
  - 木：仁慈，善良，有恻隐之心。
  - 火：热情急躁，讲礼，爱打扮。
- 长相（p29）：
  - 土：额窄、下巴方，鼻子大。
  - 金：下巴尖，人白，眼大。
  - 水：额宽，脸圆。
  - 木：额窄，脸长方。
  - 火：额宽，下巴尖，眼睛好看，近视。
- 身材、肤色（p31）：
  - 肤色：木黑、金白、土黄、火红。
  - 身材：金、木偏高；水、火中等；土偏矮。
- 转写说“木高、水黑”，和课件“木黑”有出入，以课件为准。
